# SOP: Google Folder Creation & Organization

## 1. Document Control
- **ID**: dn-seo-sop-02
- **Version**: 1.0
- **Owner Role**: Junior SEO Specialist
- **Trigger**: Client welcomes email is sent.
- **Inputs**: Client business name, agency folder structures.
- **Outputs**: Standardized Google Drive folder structure for the client.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to set up and organize the client Google Drive folder. Standardizing our files ensures that our team can locate audits, keyword research sheets, and reports instantly. It prevents files from getting lost.

---

## 3. Required Tools
- Google Drive (agency account)
- Client spreadsheet templates

---

## 4. Step-by-Step Instructions
1. **Locate Main Client Folder**
   - Action: Go to the main client folder in the Digital Neighbour Google Drive.
   - Expected Result: You see the list of active clients.
2. **Create New Folder**
   - Action: Right click, select New Folder, and name it exactly as the client business name.
   - Expected Result: A new folder is created.
3. **Create Sub-Folders**
   - Action: Inside the client folder, create four sub-folders named: `01_Onboarding`, `02_Audits_and_Research`, `03_Onpage_and_Content`, and `04_Reports`.
   - Expected Result: You see these four folders inside the client directory.
4. **Copy Spreadsheet Templates**
   - Action: Copy the standard SEO Audit Template and the Keyword Research Template into the `02_Audits_and_Research` folder.
   - Expected Result: The templates are copied and renamed with the client business name prefix.
5. **Set Share Permissions**
   - Action: Click Share on the main client folder and ensure all internal team members have editor access.
   - Expected Result: The team can read and edit all files in the folder.
6. **Log Folder Link in ClickUp**
   - Action: Copy the folder link from Google Drive and paste it into the ClickUp project brief.
   - Expected Result: The ClickUp project brief contains the folder link.

---

## 5. Quality Control & Measurable Checks
- [ ] Folder naming matches client business name exactly.
- [ ] All four sub-folders exist.
- [ ] Spreadsheet templates are copied and renamed.
- [ ] Link is pasted in ClickUp.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Cannot create folders | Account does not have correct permissions | Contact the system administrator to request editor permissions on the main Google Drive directory. |
| Templates are edited directly | User forgot to make a copy | Restore the template to its original state using version history, then copy it to the client folder. |
