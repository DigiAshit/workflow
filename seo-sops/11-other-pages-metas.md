# SOP: Meta Optimization for Other Supporting Pages

## 1. Document Control
- **ID**: dn-seo-sop-11
- **Version**: 2.0
- **Owner Role**: Junior SEO Specialist
- **Trigger**: Primary page meta titles and descriptions draft is complete.
- **Inputs**: Client website URL list, meta templates.
- **Outputs**: Drafted metas for secondary pages (About, Contact, FAQ, Blog).

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to write optimized meta titles and descriptions for supporting website pages. These pages include the About Us, Contact, FAQ, and Blog Category pages. This ensures complete site optimization.

---

## 3. Required Tools
- Google Sheets (client project folder)
- Client website CMS

---

## 4. Step-by-Step Instructions
1. **List Secondary Pages**
   - Action: Identify all active website pages that are not main service or product pages (e.g. About, Contact, Privacy, FAQ, Legal).
   - Expected Result: You have a list of secondary URLs.
2. **Draft Contact Page Metas**
   - Action: Write a meta title and description for the Contact page. Ensure you include the client phone number, business location, and a clear call to action.
   - Expected Result: Contact page metas are completed.
3. **Draft About Page Metas**
   - Action: Write a meta title and description highlighting the client history, values, team expertise, and business location.
   - Expected Result: About page metas are completed.
4. **Draft FAQ Page Metas**
   - Action: Write a meta title and description that mentions common customer questions and answers. Include relevant local keywords.
   - Expected Result: FAQ page metas are completed.
5. **Draft Blog Page Metas**
   - Action: Write a meta title and description for the main blog category pages. Include primary category keywords.
   - Expected Result: Blog page metas are completed.
6. **Check Title and Description Lengths**
   - Action: Verify that all titles are under sixty characters and descriptions are under one hundred and sixty-five characters.
   - Expected Result: Metadata lengths are correct.
7. **Save to Google Sheet**
   - Action: Paste the completed metas into the designated Other Pages section of the Meta Creation sheet.
   - Expected Result: All secondary page metadata is saved.

---

## 5. Quality Control & Measurable Checks
- [ ] Contact page optimised with business phone and location.
- [ ] About page optimised with history and location.
- [ ] FAQ page optimised with target questions keywords.
- [ ] Blog page optimised with category keywords.
- [ ] Legal pages reviewed and have basic meta tags.
- [ ] No duplicate titles exist across the site.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Contact page title is boring | Used a generic name like "Contact Us" | Make it local and active. Write "Contact [Brand Name] in [City], Phone, Map, and Email". |
| Privacy Policy meta descriptions are blank | User thought legal pages do not need metas | While legal pages do not rank for commercial keywords, write a simple description to prevent Google from showing messy text snippets. |
