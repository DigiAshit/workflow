# SOP: Meta QA and Review

## 1. Document Control
- **ID**: dn-seo-sop-19
- **Version**: 2.0
- **Owner Role**: Senior SEO Specialist
- **Trigger**: Draft meta titles and descriptions sheet is complete.
- **Inputs**: Completed Meta Creation sheet, target keyword list.
- **Outputs**: Approved meta titles and descriptions ready to be applied on site.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to review and approve meta titles and descriptions before they go live. It ensures that metadata is unique, includes the primary search term and location, and fits within Google display limits.

---

## 3. Required Tools
- Google Sheets (client project folder)
- Click-through rate optimizer tool
- Google search results mock-up tool

---

## 4. Step-by-Step Instructions
1. **Check Keyword and Location Alignment**
   - Action: Match each meta title and description against the target page keyword. Verify that the primary keyword and target location are included.
   - Expected Result: Key terms are present in the metadata.
2. **Review Character Lengths**
   - Action: Check that every meta title is under sixty characters and every description is under one hundred and sixty-five characters.
   - Expected Result: No metadata will be truncated in search results.
3. **Verify Click Appeal**
   - Action: Read the titles and descriptions to ensure they highlight a clear client benefit or unique point. Check that descriptions end with an active request (e.g. "Call now").
   - Expected Result: The copy is engaging and drives clicks.
4. **Scan for Duplication**
   - Action: Use conditional formatting in Google Sheets to highlight any duplicate titles or descriptions.
   - Expected Result: You confirm that all metadata is unique.
5. **Approve the Sheet**
   - Action: Once all checks pass, change the review status in ClickUp to Approved and log the date.
   - Expected Result: The delivery team receives the approval notification.

---

## 5. Quality Control & Measurable Checks
- [ ] Target keyword present in all metadata.
- [ ] Target location present in all metadata.
- [ ] Unique selling point (USP) present in metadata.
- [ ] No duplicate titles or descriptions exist across pages.
- [ ] Meta content matches the page search intent.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Metas are too generic | Wrote standard titles like "Home - [Brand Name]" | Rewrite using a descriptive keyword and location (e.g. "Car Mechanic Christchurch, [Brand Name]"). |
| Metadata character length is right at the limit | Used long characters (like capital W) which take up more pixel width | Test the metadata in a Google Search results simulator to check for truncation. Shorten if the text cuts off. |
