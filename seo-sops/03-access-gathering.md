# SOP: Gathering Access

## 1. Document Control
- **ID**: dn-seo-sop-03
- **Version**: 1.0
- **Owner Role**: Client Relationship Manager
- **Trigger**: Welcome email is sent or follow up is required.
- **Inputs**: Client welcome email, login details provided by client.
- **Outputs**: Verified access to GMB, website CMS, and Google Search Console.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to request, verify, and store login details for client websites, Google My Business profiles, and Google Search Console. Secure access setup allows our team to make technical changes and track campaign metrics.

---

## 3. Required Tools
- LastPass (agency password manager)
- Google Search Console
- Google My Business
- Client Website CMS (WordPress, Shopify, etc.)

---

## 4. Step-by-Step Instructions
1. **Receive Client Credentials**
   - Action: Check the client email reply for login details.
   - Expected Result: You locate the usernames, passwords, or access invitations.
2. **Verify Google My Business Access**
   - Action: Log into the agency Google My Business account and check if the client profile is visible in our dashboard.
   - Expected Result: The client business listing is visible and editable.
3. **Verify Google Search Console Access**
   - Action: Log into Google Search Console and verify that the client website property is visible.
   - Expected Result: The website traffic data is visible in the console.
4. **Verify Website CMS Access**
   - Action: Open the client website login page, enter the credentials, and log into the admin dashboard.
   - Expected Result: The dashboard loads with full administrator or editor access.
5. **Save Credentials in Password Manager**
   - Action: Create a new folder for the client in LastPass and save all login credentials securely.
   - Expected Result: Credentials are saved and shared with the delivery team.
6. **Update ClickUp Task**
   - Action: Mark the task named Gather access: Website and GMB as complete in ClickUp.
   - Expected Result: Task status updates to complete in ClickUp.

---

## 5. Quality Control & Measurable Checks
- [ ] GMB access verified with manager permissions.
- [ ] GSC access verified with owner or full user permissions.
- [ ] CMS access verified with admin or editor role.
- [ ] All logins saved in LastPass.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| CMS password does not work | Typo in the email or client reset the password | Send an email to the client asking to verify the login URL and password. |
| GSC has no data | The website property is new | Create a new domain property in GSC and ask the client to add the verification text record to their domain DNS. |
