# SOP: Keywords Research

## 1. Document Control
- **ID**: dn-seo-sop-07
- **Version**: 1.0
- **Owner Role**: Senior SEO Specialist
- **Trigger**: Client welcome email is sent or project onboarding has begun.
- **Inputs**: GSC account data, Ahrefs tool, competitor website URLs, client sitemap.
- **Outputs**: Keyword research sheet, list of mapped target keywords.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to do keyword research for local and e-commerce websites. We select high-value, relevant search terms that match user intent. Mapped keywords are then used to build the content and meta strategies.

---

## 3. Required Tools
- Google Search Console
- Ahrefs (or Google Keyword Planner)
- Google Sheets (client project folder)

---

## 4. Step-by-Step Instructions
1. **Verify Keyword Budget**
   - Action: Ask the manager how many target keywords are allowed for this client campaign.
   - Expected Result: You know the target keyword count (e.g., twenty keywords).
2. **Extract Website URLs**
   - Action: Open the website sitemap URL (usually `sitemap.xml`) and extract all active page URLs into the keyword research sheet.
   - Expected Result: All website pages are listed in column A of the sheet.
3. **Audit Existing Search Terms**
   - Action: Open Google Search Console, filter for the last three months of data, and export the top performing search queries.
   - Expected Result: You identify terms that already drive impressions and clicks.
4. **Research Competitor Keywords**
   - Action: Open Ahrefs, enter the main competitor domain name, and go to the Organic Keywords tab. Export the keywords.
   - Expected Result: You see the search terms that drive traffic to competitors.
5. **Conduct Local Keyword Research**
   - Action: Create a list of core services. Combine each service with the target client location (e.g., "mechanic Christchurch", "WOF Christchurch").
   - Expected Result: You generate location-based search terms.
6. **Conduct E-commerce Keyword Research**
   - Action: For product pages, research keywords that match the specific product title, attributes, and brand names.
   - Expected Result: You identify commercial intent keywords.
7. **Map Keywords to URLs**
   - Action: Assign one primary keyword and two secondary keywords to each target website page URL. Ensure no two pages target the exact same primary keyword to prevent cannibalisation.
   - Expected Result: Every page is mapped to unique, relevant keywords.
8. **Organize the Keyword Sheet**
   - Action: Sort the keywords by search volume and competitiveness. Highlight the primary target terms.
   - Expected Result: The sheet is clean and ready for internal review.

---

## 5. Quality Control & Measurable Checks
- [ ] Total keywords map to the campaign budget limit.
- [ ] Sitemap URLs extracted and mapped.
- [ ] Local keyword mapping includes target location keywords.
- [ ] No keyword cannibalisation exists across different URLs.
- [ ] Primary and secondary keywords assigned.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Core keywords have zero search volume in the target location | The location population is small | Use broader location terms (e.g. regional names) or focus on informational keywords with higher search volume. |
| Two pages target the same search query | Keyword cannibalisation | Review both pages. Change the focus of one page to a different keyword variation, or merge the pages. |
