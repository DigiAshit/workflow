# SOP: Filling the SEO Audit Sheet

## 1. Document Control
- **ID**: dn-seo-sop-06
- **Version**: 2.0
- **Owner Role**: SEO Specialist
- **Trigger**: Technical & On-page SEO Audit is complete.
- **Inputs**: Screaming Frog crawl data, PageSpeed scores, client project folder.
- **Outputs**: Completed Digital Neighbour SEO Audit Sheet.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to fill the client SEO Audit Sheet. It organizes our audit findings into an easy-to-read document for the client and developer. It prioritizes tasks by effort and business impact.

---

## 3. Required Tools
- Google Sheets (client project folder)
- Screaming Frog export files
- PageSpeed Insights data

---

## 4. Step-by-Step Instructions
1. **Open SEO Audit Sheet**
   - Action: Open the client Google Drive folder, go to the `02_Audits_and_Research` sub-folder, and open the copied SEO Audit Sheet.
   - Expected Result: The spreadsheet loads.
2. **Enter Project Details**
   - Action: Fill the summary sheet with the client business name, website URL, audit date, and names of competitors.
   - Expected Result: Main project metadata is populated.
3. **Fill Technical SEO Tab**
   - Action: Copy the crawl findings into the sheet. Detail the number of broken links, duplicate titles, missing meta descriptions, and multiple H1 tags.
   - Expected Result: Technical findings are logged in the sheet.
4. **Assign Task Priorities**
   - Action: Assign a priority label (High, Medium, Low) and impact score to each issue. Set high priority for broken links, missing sitemaps, and missing main page titles.
   - Expected Result: Tasks are prioritized.
5. **Add Actionable Recommendations**
   - Action: Write clear recommendations and map them to specific page URLs. Explain what changes must be made in plain language.
   - Expected Result: Recommendations are easy to understand.
6. **Format the Sheet**
   - Action: Check that all columns are readable, apply standard formatting, and remove empty rows.
   - Expected Result: The spreadsheet is clean and ready to present to the client.
7. **Complete Audit Status in ClickUp**
   - Action: Mark the task named Fill SEO Audit Sheet as complete in ClickUp.
   - Expected Result: The ClickUp task status updates to complete.

---

## 5. Quality Control & Measurable Checks
- [ ] Every audit finding added to the sheet.
- [ ] Priority assigned to every logged issue.
- [ ] Impact assigned to every logged issue.
- [ ] Target page URL included for every finding.
- [ ] Actionable recommendation included.
- [ ] No blank sections left in the sheet.
- [ ] Client-ready formatting applied.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Too many technical issues to fill manually | The website is very large | Group minor issues of the same type together (e.g. "Fifty images missing alt tags") instead of writing one line per image. |
| Recommendations are too complex | Jargon was used | Rewrite recommendations using simple terms. Focus on what is broken and how it impacts business visibility. |
