# SOP: Off-Page SEO Backlink Quality Control

## 1. Document Control
- **ID**: dn-seo-sop-31
- **Version**: 2.0
- **Owner Role**: Senior SEO Specialist
- **Trigger**: Backlink logs are submitted by the off-page team.
- **Inputs**: Google Sheets backlink tracker, builder submission logs.
- **Outputs**: Verified backlink tracker with corrections flagged and completed.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to review backlink submissions from the off-page team. It ensures that links are unique, built on quality directory sites, and match search guidelines. This helps Digital Neighbour maintain high backlink quality for Kiwi client campaigns.

---

## 3. Required Tools
- Google Sheets (client project folder)
- ClickUp
- Active backlinks log sheet

---

## 4. Step-by-Step Instructions
1. **Open Backlink Tracker**
   - Action: Open the active Google Sheets backlink tracker for the client project.
   - Expected Result: The tracking spreadsheet opens.
2. **Filter Submissions by Builder**
   - Action: Filter the rows to display submissions from specific team members like Subhra or Deepa.
   - Expected Result: You see the submissions for the selected team member.
3. **Scan for Duplicate Profile Links**
   - Action: Check the URL column to see if any profile link is repeated two or more times for the same client.
   - Expected Result: Duplicate profile links are identified.
4. **Audit Social Bookmarking (SBM) Sites**
   - Action: Review the domains used for SBM links to check if the builder relies on the same three or four blog sites.
   - Expected Result: You identify any over-use of SBM blogs.
5. **Verify Citation Relevancy**
   - Action: Check the target websites to ensure citations are built on proper directory pages instead of generic user profiles.
   - Expected Result: You identify any citation layout errors.
6. **Flag Incorrect Submissions**
   - Action: Highlight rows containing duplicate or low-quality links in red.
   - Expected Result: The broken links are marked.
7. **Add Revision Comments**
   - Action: Insert a comment on each red cell explaining exactly what the builder must fix.
   - Expected Result: Clear revision instructions are logged.
8. **Assign Revision Tasks**
   - Action: Send a link to the spreadsheet to the builder and request them to replace the flagged links.
   - Expected Result: The builder receives the request to make changes.
9. **Verify the Changes**
   - Action: Re-open the sheet after twenty-four hours to check that the red rows have been corrected and verified.
   - Expected Result: Flagged links are replaced with valid submissions.

---

## 5. Quality Control & Measurable Checks
- [ ] Submissions filtered and reviewed by builder.
- [ ] No duplicate profile links remain in the log.
- [ ] SBM links verified to use diverse domains.
- [ ] Citations verified as directory pages instead of user profiles.
- [ ] Issues flagged in red with clear review comments.
- [ ] Flagged links corrected and verified within twenty-four hours.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Builder continues to submit duplicate links | Builder does not understand the rules | Send the builder the Digital Neighbour backlink quality guidelines document and run a quick training session. |
| The tracker sheet is messy | Builders did not follow standard formatting | Lock the main spreadsheet headers and enforce standard columns layout. |
