# SOP: Meta Titles & Descriptions Creation

## 1. Document Control
- **ID**: dn-seo-sop-10
- **Version**: 2.0
- **Owner Role**: SEO Specialist
- **Trigger**: Keyword research and mapping are approved.
- **Inputs**: Mapped keyword sheet, meta creation template.
- **Outputs**: First draft of page-level meta titles and descriptions.

---

## 2. Purpose & Objectives
This Standard Operating Procedure explains how to write meta titles and descriptions for target pages. Creating optimized metas improves our click-through rates (CTR) on Google search results and targets key search terms.

---

## 3. Required Tools
- Google Sheets (client project folder)
- Keyword research sheet
- Google Search results (for competitor research)

---

## 4. Step-by-Step Instructions
1. **Open Meta Creation Tab**
   - Action: Navigate to the `03_Onpage_and_Content` folder in Google Drive and open the Meta Creation sheet.
   - Expected Result: The metadata template loads.
2. **Input Website Page URLs**
   - Action: Copy the list of website URLs from the keyword research sheet and paste them into column A.
   - Expected Result: All target URLs are listed.
3. **Identify Primary Keyword**
   - Action: Locate the assigned primary keyword for each URL in column B.
   - Expected Result: You know the target search term for each page.
4. **Draft Meta Title**
   - Action: Write a meta title that includes the primary keyword, target location (for local SEO), a unique selling point (USP), and the client brand name. Ensure the length is under sixty characters.
   - Expected Result: The title is written.
5. **Verify Title Character Length**
   - Action: Use a length formula in Google Sheets (`=LEN(cell)`) to verify the title character count is under sixty characters.
   - Expected Result: The title length is valid.
6. **Draft Meta Description**
   - Action: Write a meta description that includes the primary keyword, a call to action (CTA) like "Call today" or "Get a quote", and the client USP. Keep the length under one hundred and sixty-five characters.
   - Expected Result: The description is written.
7. **Verify Description Character Length**
   - Action: Use the formula to check that the description character count is between one hundred and twenty and one hundred and sixty characters.
   - Expected Result: The description length is valid.
8. **Check for Duplication**
   - Action: Scan the drafted titles and descriptions to ensure no two pages share identical copy.
   - Expected Result: Every meta title and description is unique.

---

## 5. Quality Control & Measurable Checks
- [ ] Primary keyword included in title and description.
- [ ] Location keyword included (optional for non-local pages).
- [ ] Unique selling point (USP) included in metadata.
- [ ] Brand name included (optional for secondary pages).
- [ ] Meta titles are under sixty characters.
- [ ] Meta descriptions are under one hundred and sixty-five characters.

---

## 6. Common Problems & Troubleshooting
| Problem | Likely Cause | Solution |
| :--- | :--- | :--- |
| Meta title is too long | Too many keywords or brand name is long | Remove filler words. Shorten the USP or use a short brand name variation (e.g. use "A1 Malaga" instead of "A1 Malaga Auto Dismantlers"). |
| Meta description lacks click appeal | Jargon or boring wording was used | Focus on the client benefit. Write a direct benefit (e.g. "Get cash for your old car today") and end with a strong command CTA. |
