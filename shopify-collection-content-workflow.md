# Shopify E-commerce Collection Content Creation Workflow

**Version:** 1.0

## Core Principles
- One step at a time.
- Stop after every major phase for approval.
- Maintain context throughout the workflow.
- Optimise for SEO, AI Search, and conversions.
- Automatically import `product-marketing-context.md` if available.

---

# Phase 0 • Project Initialisation

## Collect Inputs
- Website URL
- Collection Type (Category, Sale, Seasonal)
- Existing Collection URL (optional)
- Primary Keyword
- Secondary Keywords
- Target Country
- Target Audience
- Product URLs

Automatically search for `product-marketing-context.md` and import:
- Brand tone
- Writing style
- Brand terminology
- CTA style
- USPs
- Formatting rules
- Prohibited wording

**Output:** Project Brief

**Approval Required**

# Global Execution Rules

1. Complete one phase at a time.
2. Stop after every phase.
3. Wait for approval before continuing.
4. Preserve approved context.
5. Follow imported brand guidelines.
6. Optimise equally for SEO, AI Search and conversions.
7. Use British English.
8. Avoid keyword stuffing.
